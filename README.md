# 천리안명리연구소 AI 수강도우미

천리안명리연구소의 교육과정과 수강 정보를 편리하게 확인할 수 있도록 만든 웹페이지입니다. 화면 오른쪽 아래의 **수강도우미** 버튼을 누르면 안내창이 열리고, **수강도우미에게 질문하기**를 통해 외부 AI 수강도우미로 이동합니다.

![AI 수강도우미 배너](display-ai-banner.png)

## 주요 기능

- 교육과정, 수강 대상, 학습 내용에 관한 질문 안내
- PC와 모바일 화면에 맞춘 수강도우미 버튼
- 안내창 열기·닫기 및 `Esc` 키로 닫기

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html.html` | 수강도우미 웹페이지 |
| `display-ai-banner.png` | 안내창 상단 이미지 |
| `display-ai-icon.png` | 수강도우미 버튼 아이콘 |

## 이용 방법

`index.html` 파일을 브라우저에서 열고, 오른쪽 아래 **수강도우미** 버튼을 눌러 주세요. 안내창의 **수강도우미에게 질문하기**를 선택하면 질문 페이지가 새 창에서 열립니다.

> AI 답변은 참고용입니다. 정확한 모집 일정과 수강료는 천리안명리연구소의 공식 안내를 확인해 주세요.
